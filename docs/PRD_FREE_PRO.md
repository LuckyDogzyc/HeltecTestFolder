# 免费版 / Pro 版账号与权益 PRD

## 目标
在不要求 ESP32 刷机、OTA 或重新配网的前提下，使用户可注册账号、认领自己的设备，并按免费版或 Pro 权益使用不同的配置能力。

## 范围（第一发布切片）

### 免费版
- 可注册、登录、退出；
- 可认领一台设备；
- 可使用现有基础卡牌价格显示和官方模板；
- 不可保存图片素材、图片背景或高级自定义布局。

### Pro（先由管理员/测试接口授予，支付后接入）
- 保留免费版全部能力；
- 可保存高级自定义配置；
- 可上传并使用静态图片素材；
- 可管理更多设备（具体额度由权益配置决定）。

## 核心规则
1. 设备必须由设备自身 `deviceId + deviceKey` 注册；浏览器永远不得获取 deviceKey。
2. 用户通过一次性配对码认领设备；认领后仅设备所有者可查询、重命名或保存配置。
3. 权益只在服务端判定。ESP32 只拉取最终 `configVersion` 和可显示的 frame，不接受也不理解免费/Pro 业务逻辑。
4. 升级为 Pro 时，服务端为该用户设备递增 `configVersion`；设备下次正常唤醒拉取新配置，无需 OTA。
5. 前端隐藏无权限入口不是安全边界；所有保存高级配置、上传素材和变更权益的 API 必须在服务端校验。
6. 重置必须分为“仅重配网络”和“解绑/转让设备”两种；前者绝不影响账号归属或 Pro 权益，后者必须由已登录所有者操作并要求设备侧本地确认。

## 设备重置与换网

### 仅重配 Wi-Fi（用户换家庭/办公室网络）
- 用户在设备本地 AP 配网页选择“更换 Wi-Fi”，或通过设备上的本地物理操作进入配网模式；
- 清除 SSID、密码和网络重试状态，保留 `deviceId`、`deviceKey`、设备 owner、套餐权益、已保存的云端配置和本地 frame；
- 设备立即重启到配网 AP，完成新 Wi-Fi 配置后使用原设备身份连接云端；
- 不重新绑定账号、不要求重新购买 Pro、不需要 OTA。

### 解绑/转让设备（更换主人）
- 仅当前设备 owner 可从云端发起“解绑设备”；
- 服务端将解绑请求标为待确认，禁止直接远程删除 owner；
- 用户必须在设备本地 AP 页面或物理按键确认；确认后服务器删除 owner 关系、废止旧配对码、生成新的短时配对码，并将云端可见配置恢复为免费版基础默认值；
- `deviceId`、`deviceKey` 作为设备身份保留，不能被浏览器导出或重置为公开值。

### 出厂恢复/售后恢复
- 物理本地触发，清除 Wi-Fi、用户可编辑配置、缓存 frame 和本地状态；保留设备身份；
- 设备重启进入 AP 配网和待认领状态；云端需要通过售后管理员流程或原 owner 确认后才能解除旧 owner，避免拾获者直接抢占已认领设备。

## 数据模型
- `users`：id、email（唯一）、password_hash、created_at；
- `sessions`：opaque token hash、user_id、expires_at；
- `devices`：device_id、device_key_hash、显示/状态/配置字段；
- `device_owners`：device_id、user_id、claimed_at；
- `entitlements`：user_id、plan（free/pro）、有效期；
- `pairing_codes`：device_id、code_hash、expires_at、used_at；
- `assets`：owner_user_id、文件元数据、存储位置、仅 Pro 可创建。

## 设备协议约束
维持当前低功耗协议：设备唤醒时注册/心跳，再按版本拉取配置；无变更返回 `304`。图片或高级模板必须由云端预先转换为设备已支持的黑/红双平面静态 frame，设备不新增图片解码器。

## 验收
- 两个用户不能访问或修改对方设备；
- 免费用户请求 Pro 配置/图片素材 API 返回 `403`；
- Pro 用户可保存高级配置；
- 切换用户为 Pro 后，对应设备配置版本变化；
- 设备端协议字段不因权益体系变更而要求固件升级。
